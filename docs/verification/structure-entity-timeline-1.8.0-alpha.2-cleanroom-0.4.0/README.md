## 缺陷与修复

编辑器默认三步「显示选区 / 等待 20 tick / 结束」在时间轴为 0 时仍绘制结构内火花，而方块尚未显示。
根因是 `PonderScene.begin()` 将结构载入的实体设为独立可见元素。

结构实体现在以原始局部位置关联选区：位于空气且下方有方块时依附该方块（魔力池和箱子上方的火花），否则依附所在格。
它们随选区显示、隐藏、移动和旋转，重播与关键帧恢复重新计算可见性。
悬空实体的格子计入 `everywhere` 和显示指令。Java / JSON / ZenScript 显式创建的实体仍在创建指令执行时出现。
修复只改变结构实体的显示规则；实体数据与原生渲染器保留。
已有包含实体的 NBT 无需重新捕获，场景无需为此修改脚本。
