# 1.8.0-alpha.2 — 结构实体跟随时间轴

本地开发测试包，包含 alpha.1 的可配置主题系统。

修复编辑器预览和播放器在时间轴 0 刻就绘制结构内火花的问题。
结构捕获或 NBT 导入的实体现在跟随所属选区的显示、隐藏、移动和旋转；
倒拖至 0、重播及关键帧恢复同步恢复实体的显示状态。
魔力池等方块上方的实体跟随下方的依附方块，其他实体跟随所在格。
悬空实体也可通过 `showSection(everywhere)` 显示。

脚本和 Java 显式创建的实体继续在创建指令执行时出现。
已有包含实体的 NBT 不需要重新捕获；JSON / ZenScript 场景无需为此修改。

最低运行环境为 Minecraft 1.12.2 / Cleanroom 0.4.0 正式版（无 `-alpha`）/ Java 25。
本轮验收记录见 [实体时间轴验收](../verification/structure-entity-timeline-1.8.0-alpha.2-cleanroom-0.4.0/README.md)。
