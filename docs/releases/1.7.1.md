- Add `GuiDemoLayout` for complete passive GUI appearances, with nested groups, stable paint layers and clipping.
- Resolve tutorial highlights from the same nodes that draw the controls, including visible text bounds and side panels.
- Keep modal windows above ordinary controls and remove highlights for hidden controls.
- Correct fractional-scale edge rounding. Existing JSON-only GUI demonstrations retain their renderer.
- Support native passive widgets through client adapters without opening machine containers or sending GUI actions.
