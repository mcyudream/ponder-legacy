# Ponder Legacy 1.7.1

- Expose read-only `GuiDemoState` in the standalone API jar, so addon layout providers do not depend on implementation session classes.
- Schedule disconnect cleanup and addon scene registration on the client thread, preventing registry access during Netty teardown.
- Reserve the footer hint and playback controls when fitting standalone GUI demonstrations, including tall layouts and small windows.

- Add `GuiDemoLayout` for complete passive GUI appearances, with nested groups, stable paint layers and clipping.
- Resolve tutorial highlights from the same nodes that draw the controls, including visible text bounds and side panels.
- Keep modal windows above ordinary controls and remove highlights for hidden controls.
- Correct fractional-scale edge rounding. Existing JSON-only GUI demonstrations retain their renderer.
- Support native passive widgets through client adapters without opening machine containers or sending GUI actions.

Minecraft 1.12.2, Java 25, and official **Cleanroom 0.4.0**. Ponder's 336 unit tests, 243 client checks and 11 dedicated-server checks pass on the production jar. AE2S-specific layouts are supplied and verified by AE2S Ponder Legacy 0.4.0.

This is a main CI development build. No release tag is created by this change.
