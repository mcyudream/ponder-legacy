# Ponder Legacy 1.8.0

- 新增经典与现代 Ponder 主题。现代主题对照官方高版本源码校准标题、按钮外框、底部控件、旁白引线和细进度条，支持背景模糊及小窗口。
- 新增 `/pondertheme` 选择、保存和重载主题；切换主题保留当前场景、时间、暂停状态和视角。
- 主题开放 JSON、ZenScript 和资源包控制：支持新建、继承、局部覆盖和整合包默认值，尊重玩家自己的主题选择。示例见发布资产 `ponder-theme-examples-1.8.0.zip`。
- 修复捕获或导入的火花在时间轴 0 刻提前出现。结构实体现在随所属选区显示、隐藏和变换，倒拖、重播及关键帧恢复同步恢复初始隐藏状态；脚本显式创建的实体仍按创建指令出现。

**替换旧 Ponder JAR。已有 NBT 中包含火花数据时无需重新捕获，也无需修改现有场景脚本。** 更早版本捕获且未包含实体数据的 NBT 仍须重新捕获。

Minecraft 1.12.2 / Java 25 / **Cleanroom 0.4.0 正式版（无 `-alpha`）**。
植魔、CraftTweaker、MMCE、Revo UI 等外置联动保持可选；JSON 主题无需安装 CraftTweaker。

主题手册：`docs/UI-THEMES.md`。`Theme.create`、`Theme.extend`、`Theme.modify` 和 `Theme.setDefault` 提供 ZS 主题接口；本地 JSON 位于 `config/ponder/themes.json`。

发行安装包在正式 CR 0.4.0 上验收，覆盖真实植魔七种火花的结构捕获、原版 NBT 导入、Java、JSON、实际 ZenScript 路径，以及编辑器/播放器 0 刻、延迟显示、移动、隐藏、回拖和重播。主题切换、资源包/JSON 重载、小窗口、原生机器 GUI、指南、编辑器、投影及专用服务器同时回归。

361 项单元测试、1316 项正式安装包运行检查通过。

运行环境为 Linux x86_64 / llvmpipe；验收报告和安装包指纹见 `docs/verification/release-1.8.0-cleanroom-0.4.0/summary.json`。
