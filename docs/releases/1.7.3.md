# Ponder Legacy 1.7.3

- 修复结构框选捕获遗漏实体的问题，保留选区内的植魔普通火花、四种升级火花，以及普通／主多媒体火花和对应 NBT。
- 新增 JSON `world.create_entity` 和 ZenScript `scene.world.createEntity`，按注册 ID 和可选 NBT 创建原版或 Mod 实体。
- 修复虚拟世界实体范围查询，以及不同实体数字 ID 相同时被误判为重复的问题；初始化实体插值位置，保证首次播放、重播和进度回拖时位置正确。
- 保持植魔和 CraftTweaker 可选，JSON、Java API 与结构捕获可独立使用。

**升级后，旧 NBT 若未保存火花实体，需要重新框选保存。选区须包含火花所在的空气层。** 客户端和服务端均替换旧 Ponder JAR。

Minecraft 1.12.2 / Java 25 / **Cleanroom 0.4.0 正式版（无 `-alpha`）**。

发行安装包在该基线上通过框选捕获、独立原版 NBT 导入、Java、JSON 和实际 ZenScript 五条路径的客户端验收，覆盖七种火花、重播和回拖。70 次逐实体 framebuffer 比较通过；另验证未安装植魔／CraftTweaker 的客户端，以及安装和未安装植魔的专用服务器。植魔验收版本为 Botania r1.10-364.4、Baubles 1.12-1.5.2，ZenScript 使用 CraftTweaker 4.1.20.698。

346 项单元测试通过。完整产物指纹见 `docs/verification/release-1.7.3-cleanroom-0.4.0/summary.json`。运行验收平台为 Linux x86_64 / llvmpipe。
